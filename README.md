# ぷよてと 〜魔王サタンの逆襲〜 😈

ぷよぷよとテトリスが1つになった、ブラウザで遊べるパズルゲームです。
プレイヤーは **魔王サタン**。連鎖やテトリス消しのたびに掛け声で吠えます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(インストール・ビルド不要)。

```bash
# ローカルで開く場合
open index.html        # mac
# または適当なローカルサーバで
python3 -m http.server 8000
```

## モード

### 🌀 フュージョン(1人用)
**1つの盤面にぷよとテトリミノが両方降ってくる**合体モード。本家ぷよぷよテトリスの「ぷよテトミックス」ルールに準拠。

- 盤面は **8×17**。**ぷよ4ターン → テトリミノ4ターン** の交代制でツモが来る
- ぷよは同じ色を **4つ以上** つなげると消える
- テトリミノは **横1列** そろえると消える(ぷよが混ざっていてもOK)
- テトリミノは**ぷよの上に乗れず、ぷよを潰しながら下へ沈む**。
  床か他のブロックに着地すると、潰されたぷよが**その列の上から同じ並びで降ってくる**
- 連鎖表示が出ている**一定時間内に新たに消せば連鎖がつながる**(「X連鎖 + Yライン」)。
  ぷよ消しとライン消しを混ぜると**ミックス連鎖ボーナス**
- 消えたぷよのとなりのブロックも巻き込んで消える
- どんどん落下が速くなる。ハイスコアを目指せ!

### 😈 VS:ぷよで戦う
サタン(ぷよぷよ)vs CPU(テトリス)。連鎖で相手におじゃま段を送り込め!

### 🟦 VS:テトリスで戦う
サタン(テトリス)vs CPU(ぷよぷよ)。CPUは連鎖を組んでくるぞ。テトリス(4列消し)で反撃だ!

VSモードは攻撃の相殺あり。相手の盤面を埋めれば勝ち。
CPUの強さは「よわい / ふつう / つよい」の3段階。

## 操作

| キー | 動作 |
|---|---|
| ← → | 移動 |
| ↓ | 高速落下 |
| スペース | ハードドロップ |
| Z | 左回転 |
| X / ↑ | 右回転 |
| C / Shift | ホールド(落下中のぷよ/ミノを保存ボックスと交換。1手につき1回) |
| P | ポーズ |
| M | 掛け声の音声 ON/OFF |
| Enter | スタート / リトライ |

スマホ・タブレットでは画面下のタッチボタンで操作できます。

## サタンの掛け声 🔊

吹き出し+音声合成(Web Speech API)の低音ボイスで吠えます。

- 連鎖(1〜11連鎖): 「フンッ」「おろかな」「ゆくぞ」「覚悟はいいか!?」「見るがいい!」「それで本気か!?」「ディザスター」「ジャガーノート!」「カタストロフ!」「カタクリズム!」「アセンショーン!」
- テトリス(4ライン消し): 「テトリスだ」
- ゲーム開始: 「身の程知らずが…」
- ダメージ小/大: 「やるなぁ」/「いでぇっ!!」
- 勝利: 「わたしに逆らうからだ」 敗北: 「ありえん!ウソだぁぁ!」

右上の「🔊 声ON」ボタンか M キーでいつでも消せます。

## メモ

フュージョンは本家ぷよぷよテトリスの「ぷよテトミックス」ルールを参考にしています
([SEGA公式ルール](https://puyo.sega.jp/puyopuyotetris/rule/mix/index.html) /
[Puyo Nexus Wiki: Fusion](https://puyonexus.com/wiki/Fusion))。

- ツモはぷよ4ターン↔テトリミノ4ターンの交代制
- テトリミノはぷよの上に乗れず、潰しながら沈む。着地すると潰されたぷよが上から降ってくる
- 設置済みブロックもつながった固まりのまま形を保ち、ライン消し後などはぷよを押しのけて沈む
  (ブロックの下に残ったぷよは上へ押し出される)
- 連鎖は時間内に消し続ければ次のツモでもつながる(ミックス連鎖対応)
