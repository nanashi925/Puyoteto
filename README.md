# ぷよてと 〜魔王サタンの逆襲〜 😈

ブラウザで遊べる「ぷよぷよテトリス」風の対戦パズルゲームです。
プレイヤーは **魔王サタン** としてぷよぷよ側を操作し、テトリスを操る CPU と対戦します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(インストール・ビルド不要)。

```bash
# ローカルで開く場合
open index.html        # mac
# または適当なローカルサーバで
python3 -m http.server 8000
```

## ルール

- 左がプレイヤー(ぷよぷよ)、右が CPU(テトリス)
- 同じ色のぷよを **4つ以上** つなげると消える。連鎖するほど強力!
- 連鎖で CPU 側に **おじゃま段** を送り込み、CPU のライン消去でこちらに **おじゃまぷよ** が降ってくる
- 攻撃は相殺あり。相手の盤面を埋めれば勝ち!
- 3列目の上(×印)が埋まると「ばたんきゅ〜」で負け

## 操作

| キー | 動作 |
|---|---|
| ← → | 移動 |
| ↓ | 高速落下 |
| Z | 左回転 |
| X / ↑ | 右回転 |
| P | ポーズ |
| M | 掛け声の音声 ON/OFF |
| Enter | スタート / リトライ |

スマホ・タブレットでは画面下のタッチボタンで操作できます。

## サタンの掛け声 🔊

連鎖すると魔王サタンが吹き出し+音声合成(Web Speech API)で吠えます。

- 1連鎖「ジュガム!」
- 2連鎖「バランガ!」
- 3連鎖「ディアキュート!」
- 4連鎖「アブラカタブラ!」
- 5連鎖「カタストロフィ!!」
- 6連鎖以上「これぞ魔王の真の力よーっ!!」

全消し・被弾・勝利・敗北時にもいろいろ喋ります。
右上の「🔊 声ON」ボタンでいつでも消せます。

## CPU の強さ

スタート画面で「よわい / ふつう / つよい」から選択できます。
(思考速度・操作速度・ミス率が変わります)
